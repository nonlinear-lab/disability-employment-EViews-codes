# disability-employment-EViews-codes-
This analysis investigates the impact of the COVID-19 pandemic on the employment outcomes of people with disabilities using microdata from the American Community Survey. Treating the pandemic as an exogenous labour-market shock, the analysis employs a difference-in-differences framework to estimate changes in the disability-employment
This repository includes data and EViews code for estimation
0. Disability_Employment dataset from American Community Survey(Public Use Microdata Sample (PUMS) Dataset) 2017_2019 and 2021_2023
https://www.census.gov/data/datasets/2000/dec/microdata.html
EViews codes are as follows
01 EViews codes for Baseline difference-in-differences (Did) analysis (dependent variable: employment, method: OLS)
02 EViews codes for Robustness analysis(1) with difference-in-differences (Did) analysis (dependent variable: at-work)
03 EViews codes for Robustness analysis(2) with difference-in-differences (Did) analysis (dependent variable: unemployment)
04 EViews codes for Robustness analysis(3) with difference-in-differences (Did) analysis (dependent variable: non in labour force)
05 EViews codes for Robustness analysis(4) with difference-in-differences (Did) analysis (method: logistic regression)
06 EViews codes for Heterogenous analysis(1) with difference-in-differences (Did) analysis (gender=0: male vs gender=1: female)
07 EViews codes for Heterogenous analysis(2) with difference-in-differences (Did) analysis (non_white=0: white vs non_white=1: non_white)
08 EViews codes for Heterogenous analysis(3) with difference-in-differences (Did) analysis (non_hs_diploma=0: high school diploma and above vs non_hs_diploma=1: no high school diploma)
09 EViews codes for Heterogenous analysis(4) with difference-in-differences (Did) analysis (young=0: non-young vs young=1: young)
10a EViews codes for additional analysis in discussion(a) with difference-in-differences (Did) analysis (SCHL>=8: elementary school graudate vs SCHL<8:elementary school leaver)
10b EViews codes for additional analysis in discussion(b) with difference-in-differences (Did) analysis (SCHL>=11: middle school graudate vs SCHL<11:middle school leaver)
10c EViews codes for additional analysis in discussion(c) with difference-in-differences (Did) analysis (SCHL>=21: college graduate vs SCHL<21: non-college graduate)
